# Calories Predictor

## Dataset

This project utilizes the **Food.com Recipes and Reviews** dataset, which is publicly available on Kaggle.

* **Source:** [Food.com Recipes and Reviews by irkaal](https://www.kaggle.com/datasets/irkaal/foodcom-recipes-and-reviews)

To train models, install recipes.csv from the dataset and place in data/ folder.

## Run
Run the app:
```bash
streamlit run app.py
```
